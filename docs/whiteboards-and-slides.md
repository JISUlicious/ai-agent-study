## 정한 것과 그 이유

- **구성요소 네 가지:** LLM, Memory, Agent Loop, Planning, Harness를 검토했고, Planning은 LLM에 흡수되고 Harness는 루프를 감싸는 틀로 보아
  LLM, Tool, Memory, Agent Loop로 정했습니다. Harness는 발표에서 따로 언급합니다.
- **메모리 구분:** 장기/단기 대신 내부(컨텍스트 안)와 외부(저장소)로 나눴습니다. 내부 메모리는 에이전트의 작업 기록(trajectory)입니다.
- **네 기둥의 경계:** 기둥을 칼같이 나누기 어려워, 여러 기둥에 걸치는 노드는 경계선 위에 두는 방식을 택했습니다.
- **시간 순서 점검:** 구성요소 보드의 선 중 몇 개는 날짜상 거꾸로였습니다(예: Planning → Agent loop). 선은 "재료 관계"로 두고, 슬라이드에 시간 순서가 아니라고 명시했습니다.

## 구성요소 슬라이드

`agent-components-slides.html`은 구성요소 보드에서 만든 인터랙티브 웹 슬라이드입니다.

- 전체 다이어그램, 기둥(섹션)별 강조, 노드별 연결 강조를 지원합니다.
- 노드마다 이전 노드에서 이어받은 것, 발전 이유, 다음으로 넘기는 키워드를 보여 줍니다.
- 한국어 위주이며 주요 용어는 영어로 씁니다. 공통 기반 층도 별도 섹션입니다.
- 보드와 자동으로 연동되지 않습니다.

## 발표 슬라이드 구성 보드의 작성 기준

발표 슬라이드 구성 보드(https://claude.ai/artifact/4DMCbNKff4V72NVq7hM9CN)의 슬라이드 카드는 아래 기준으로 씁니다. 2026-11-18에 구성안 A~D와 확정안 전체를 이 기준으로 교정했습니다.

- 은유와 비유를 쓰지 않습니다. 예: "메우다", "해부", "컨텍스트가 찬다"를 "대응한다", "분해한다", "Context window를 관리한다"로 바꿨습니다.
- 기술 용어만 씁니다. 일반적으로 통용되는 용어(Next token prediction, Tool use, Agent loop, Context window, Chain-of-Thought, Fine-tuning 등)는 원래 표기를 그대로 씁니다. 통용 용어가 아니라 설명형 문구인 노드 이름만 짧은 명사로 줄입니다. 예: Stops before the task is done → 조기 종료, Non-deterministic behavior → 비결정성, Knowledge limitation → 지식 한계, Multi-step reasoning → 다단계 추론, Goal / Ralph Loop → Goal.
- 제목은 용어 하나와 명사 하나로 씁니다. 동사는 쓰지 않습니다. 예: "Tool use 실행".
- 내용은 핵심 개념 하나(굵게)와 주변 개념 3~4개의 관계로 씁니다. `→`는 이어짐, `⇢`는 한계의 원인, `←`는 역방향 설명입니다.

주변 개념을 3~4개로 제한하면서 일부 항목이 빠졌습니다(예: Harness 장의 Permission). 설명 문장을 없애고 관계만 남긴 것은 슬라이드 한 장이 그래프의 한 부분과 일대일로 대응하게 하기 위해서입니다.

## 환각 대응 두 갈래의 슬라이드 반영

구성요소 v2 보드(llm-to-agent-evo)에 생긴 `Hallucination → Verify output, express uncertainty → ReAct` 갈래와 `Knowledge limitation ⇢ Hallucination` 점선을 슬라이드 구성 보드에 넣었습니다.

- 확정안과 C안: "지식 한계 보충" 장에서 Hallucination을 떼어 "Hallucination 대응" 장을 새로 두었습니다. 확정안은 12장, C안은 11장이 됐습니다. "지식 한계 보충" 장에는 빠져 있던 Training dataset(원인)을 다시 넣었습니다.
- 새 장의 내용: `지식 한계 · Next token prediction ⇢ **Hallucination** → RAG · 출력 검증`. 원인 둘과 대응 둘로 주변 개념 4개를 채웠고, 검증이 이어지는 ReAct는 Agent loop 장에서 다룹니다.
- B안: "ReAct 반복" 장의 입력에 출력 검증을 추가하고, 주변 개념 4개 제한에 맞춰 Internal memory를 뺐습니다(5장 "Memory 역추적"에 이미 있음).
- A안과 D안: Hallucination이나 ReAct가 중심인 장이 없어 바꾸지 않았습니다.
- "Verify output, express uncertainty"는 설명형 문구라 "출력 검증"으로 줄였습니다.

대안으로 기존 "지식 한계 보충" 장에 출력 검증만 덧붙이는 방법이 있었지만, 주변 개념이 5개를 넘고 환각의 두 원인이 드러나지 않아 택하지 않았습니다.

## 슬라이드 디자인 시안

Claude Design 캔버스에 시안 다섯 가지를 만들었습니다: https://claude.ai/artifact/3rBWAynJx65uhgmbJsygap

조건은 미니멀리즘과 포인트 컬러 하나입니다. 시안마다 1280×720 슬라이드 세 장(제목, 관계 그래프 내용, 선형 흐름 내용)을 한 아트보드에 나란히 두었고, 포인트 컬러는 아트보드의 Tweaks에서 바꿀 수 있습니다. 내용은 확정안의 5장(Hallucination 대응)과 2장(한계 대응)을 썼습니다.

| 시안 | 바탕 | 포인트 컬러 | 글꼴 | 특징 |
|---|---|---|---|---|
| A. Swiss Grid | 흰색 | 빨강 #D92B1E | Inter, Noto Sans KR | 왼쪽 정렬, 가는 괘선, 각진 테두리 노드 |
| B. Mono Dark | 검정에 가까운 어두운색 | 라임 #B4F03C | IBM Plex Mono, IBM Plex Sans KR | 고정폭 글꼴, 핵심 노드는 색 테두리 |
| C. Editorial Serif | 푸른 기가 도는 밝은 회색 | 코발트 #1F3DFF | Noto Serif KR, Noto Sans KR | 가운데 정렬, 상자 없는 글자 노드 |
| D. Outline Numeral | 밝은 회색 | 주황 #F0591E | Space Grotesk, Noto Sans KR | 윤곽선 장 번호, 알약 모양 노드 |
| E. Accent Ground | 제목은 포인트 컬러 전면, 내용은 흰색 | 보라 #5B3DF5 | Gothic A1 | 굵은 글자, 채운 블록 노드 |

디자인은 시안 D로 정했습니다(2026-11-18). 고르면서 다음을 고쳤습니다. 시안 이름은 그대로 둡니다.

- 제목 장의 원을 지우고, 제목 위에 포인트 컬러 선(120×4px)을 두었습니다.
- 장 번호를 윤곽선 큰 숫자에서 작은 회색 숫자(16px)로 바꿨습니다. 포인트 컬러는 제목 선과 핵심 노드에만 남습니다.
- 관계 그래프 노드 위의 분류 표기(한계, 기법, 대응)를 지웠습니다. 흐름 장에서 노드 아래에 둔 예시는 그대로입니다.

설명 문장을 한두 개 넣을 때의 모습을 보려고 시안 D에 슬라이드 두 장을 더했습니다(아트보드 너비 4032 → 6688px). 같은 5장 내용에 문장 위치만 다릅니다.

- 제목 아래: 제목 바로 밑에 22px 본문으로 두고 그래프는 그 아래에 둡니다. 읽는 순서가 제목, 문장, 그래프입니다.
- 그래프 아래: 왼쪽 아래에 짧은 포인트 컬러 선과 함께 두고 범례는 오른쪽으로 옮깁니다. 그래프를 먼저 보고 문장으로 정리합니다.

설명 문장의 위치는 "그래프 아래"로 정했습니다(2026-11-18). "제목 아래" 장은 비교용으로 아트보드에 남아 있습니다.

문장은 ai-wiki로 확인한 내용(RAG는 환각을 줄이지만 없애지 못한다)만 썼습니다.

발표자와 날짜는 `[발표자]`, `[날짜]` 자리표시로 두었습니다. 시안별로 아트보드 하나에 세 장을 묶은 것은 비교가 쉽고 파일 수가 적기 때문이며, 시안이 정해지면 장마다 아트보드를 나눕니다. 렌더링 결과는 확인하지 않았습니다.
