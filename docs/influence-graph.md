# AI 에이전트 영향 그래프

`index.html`, `app.js`, `board.js`, `data.js`, `style.css`로 이루어진 페이지입니다.
"ai agent lec" 세션에서 만든 작업물이며, 이 저장소를 만들 때 함께 올렸습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 뼈대 |
| `app.js` | 시간축 위에 트랙(레인)별로 노드를 그리고, 선택한 항목의 근거를 옆 패널에 보여 줍니다. |
| `board.js` | 작업 캔버스. 그래프에서 끌어온 항목을 직접 연결하고 Mermaid로 내보냅니다. |
| `data.js` | 노드, 연결, 근거 데이터. 출처는 ai-wiki의 정리 문서들입니다. |
| `style.css` | 스타일 |

## 메모

- 데이터의 근거 강도는 ai-wiki 기준입니다. 사실 확인은 ai-wiki 세션에 문의합니다.
- 이 문서는 저장소를 만들면서 파일 머리말을 보고 작성한 것입니다. 자세한 설계는 "ai agent lec" 세션의 기록을 참고합니다.
