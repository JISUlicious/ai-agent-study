# 발표 목차: AI 에이전트 — 개념 · 기능 · 구성요소

근거는 [concept-function-component-research.md](concept-function-component-research.md)와 [sources/agent-modules-mapping.md](sources/agent-modules-mapping.md)에 있습니다.

## 조건

- 시간: 1시간. 본문 약 50분 + 질의와 여유 약 10분.
- 청중: 초급 · 중급 엔지니어. 도메인은 웹, ML, 제조 등으로 다양함.
- 그래서: 프레임워크 이름이나 코딩 에이전트에 기대지 않고, 세 도메인에 모두 맞는 공통 예시 하나를 끝까지 씁니다. 3부 코드는 의사코드 수준으로 둡니다.

## 공통 예시: "이상 원인 조사"

같은 모양의 작업이 도메인마다 있습니다. 데이터를 찾아보고, 원인을 좁히고, 보고하거나 조치를 제안합니다.

| 도메인 | 상황 | 에이전트가 쓰는 도구 예 |
|---|---|---|
| 웹 | 어젯밤 5xx 오류 급증 | 로그 검색, 배포 이력 조회, 대시보드 |
| ML | 학습 중 loss 발산 | 실험 기록 조회, 설정 diff, 학습 재실행 |
| 제조 | 라인 불량률 상승 | MES · 설비 데이터 조회, SPC 차트, 정비 이력 |
